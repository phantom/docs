# Repository instructions

## Purpose
This repository contains legacy Phantom developer documentation and has been superseded by `phantom/docs-v2`.

## Layout
Documentation is organized as Markdown files and topic directories from the repository root. GitBook assets live in `.gitbook/`.

## Working in this repository
- Treat `README.md` as the authoritative notice that active documentation has moved to `phantom/docs-v2`.
- Preserve existing GitBook front matter and link conventions when editing legacy pages.
- The repository does not define build, test, or lint commands; validate Markdown links and formatting relevant to the files changed.
